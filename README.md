# How to install
folders in this repo are invididual exports of versions. Inside them there are 2 files that need to be downloaded in the same file. To download click on the file name and search for downward arrow it is there you can find it. After downloading run the .exe file.

# Game controls
- *interact* 'R'
- *attack* 'left mouse click'
- *move* 'wasd + space'
- *switch meele/magic* 'E'
- *block/activate ability (depends on meele/magic)* 'right mouse click' (being developed)
